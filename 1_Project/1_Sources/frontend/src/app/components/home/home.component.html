Acerca de esta plantilla

Esta es una plantilla base de proyecto que incluye las funcionalidades esenciales para comenzar a desarrollar aplicaciones web con Angular y Node.js.

Características Incluidas

  • Sistema de autenticación con JWT
  • Gestión de usuarios y roles
  • Sistema de permisos granular
  • Comunicación en tiempo real con WebSocket
  • Sistema de envío de emails
  • Recuperación de contraseña
  • Base de datos MySQL con Sequelize
  • Configuración Docker lista para usar
